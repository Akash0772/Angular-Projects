# 🚀 Angular Front-end Development Portfolio

### 🌟 Project Overview

This repository is a dedicated collection of modern **Angular** projects, serving as a comprehensive showcase of strong expertise in building scalable, maintainable, and highly responsive Single Page Applications (SPAs). These applications are designed to efficiently consume **RESTful APIs** (often built with Spring Boot) and deliver excellent user experiences.

### ✨ Core Angular Skills Demonstrated

* **Modular Architecture:** Effective use of Angular Modules to segment application features and promote lazy loading.
* **Component Communication:** Expert implementation of Input/Output decorators and ViewChild for seamless parent-child interaction.
* **State Management & RxJS:** Utilized Observables and RxJS operators for asynchronous data handling and efficient state management.
* **Routing & Guards:** Implementation of advanced routing techniques, including route protection (Guards) for secure navigation.
* **HTTP Service Integration:** Creation of reusable Angular Services to handle API calls, perfectly integrating with Java Spring Boot backends.
* **Reactive/Template-Driven Forms:** Proficiency in creating complex forms with built-in validation.

### ⚙️ How to Run Locally

1.  **Prerequisites:** Ensure **Node.js** and **Angular CLI** are installed.
2.  **Clone:** Clone this repository.
3.  **Navigate:** Move into the desired project folder (e.g., `cd Project 1st/cloudkitchenweb`).
4.  **Install Dependencies:** Run `npm install`.
5.  **Serve:** Run the application using `ng serve --open`.
